# 界面设计

## 1. 设计原则

- **安静**：没有仪表盘、没有密集表格、没有营销入口。一次只做一件事：把视频变成字幕。
- **层次**：标题、说明、控件、辅助信息四层；用留白而不是分割线来分组。
- **圆润**：大圆角卡片、胶囊分段控件、圆形状态点；不做锐利边框。
- **克制**：强调色只用于主操作、选中态和进度；正文接近黑色，辅助文字为中性灰。
- **可信**：密钥、隐私和模型信息在设置里说清楚，不用模糊的“安全”口号。
- **Apple 风格，不是 Apple 复制品**：不打包 SF Pro，不使用 Apple 商标或系统图标；使用系统可用字体和原创线性图标。

## 3. 布局

```text
┌──────────────────────────────────────────────────────────┐
│ ○ ○ ○              千问字幕                              │ 46px title bar
├────────────┬─────────────────────────────────────────────┤
│ 品牌        │  WORKBENCH                                  │
│ 工作台      │  把视频，变成好字幕。          [开始生成]  │
│ 设置        │  千问 ASR · Qwen-MT · 一次生成    大陆版    │
│ 关于        │  ┌───────────────────────────────────────┐  │
│            │  │ 视频                                  │  │
│            │  │ [拖入视频，或选择文件]        [选择]  │  │
│            │  └───────────────────────────────────────┘  │
│            │  ┌───────────────────────────────────────┐  │
│            │  │ 字幕设置                              │  │
│            │  │ 识别语言 / 翻译为 / 字幕内容          │  │
│            │  │ ASR 模型 / 翻译模型                   │  │
│            │  │ 文件格式 / 服务地区                   │  │
│            │  └───────────────────────────────────────┘  │
│ 密钥保险箱 │  （运行后出现进度卡，自动滚动到可见）       │
```

- 侧栏固定 208px；内容可滚动。
- 主操作始终在右上角，不因滚动而消失。
- 运行后进度卡出现在内容底部并自动滚动到可见位置。
- 设置页内容较窄（最大 760px），形成阅读节奏。

## 4. 组件

### 标题栏

- 无边框窗口；**最左侧是带地球图标的三语下拉菜单**，中间应用名。
- **最小化/最大化/关闭按 Windows 习惯放在右上角**，每个 46×46px；关闭按钮悬停为红色，其余为浅灰。
- 双击标题栏最大化；拖动移动；右下角尺寸手柄。
- 最大化时去掉外边距、圆角和阴影。

### 侧栏

- 品牌图标 + 名称 + `SUBTITLE STUDIO` 小字。
- 三个导航按钮：选中态为白色圆角胶囊。
- 底部隐私卡：锁图标 + “密钥仅保存在本机” + “Windows 加密 · 不会进入仓库”。
- 版本号小字。

### 分段控件

- 背景 `#E9E9EE`，内边距 3px，选中项白色圆角。
- 用于：字幕内容（3 项）、文件格式（3 项）、服务地区（2 项）、界面语言（3 项）。

### 视频卡片

- 空状态：虚线拖拽区 + 蓝色胶片图标 + “拖入视频，或选择文件”。
- 已选状态：圆角缩略图 + 文件名 + `MP4 · 00:04 · 640×360 · 41.5 KB` + 更换/移除。
- 缩略图在 FFmpeg 失败时回退为自绘山形占位图。

### 运行按钮

- 主按钮蓝色胶囊，固定右上角；无视频时禁用。
- 有视频但未保存 Key 时按钮可用，下方出现琥珀色“需要 API Key”；点击后弹出带“去设置”的错误弹窗。
- 运行中按钮变为“进行中”并禁用。

### 进度卡

- 自动出现；顶部 Spinner + “正在生成字幕” + 百分比。
- 8px 圆角进度条。
- 三段步骤：语音识别 / 翻译 / 写出字幕。
  - 激活：Spinner + 蓝色状态。
  - 完成：绿色浅底 + ✓。
  - 跳过：灰色短横线（仅原文模式的翻译）。
  - 失败：红色浅底 + `!`。
- 取消按钮；完成后显示结果路径、再生成、打开字幕、打开文件夹。

### 完成弹窗

- 白色圆角卡片，56px 绿色 ✓ 圆形图标。
- 标题“字幕已生成”，副文案“共 N 条字幕，已保存到：”，路径可选。
- 按钮：完成 / 打开字幕 / 打开文件夹。
- 「打开文件夹」会使用 `explorer /select,` 定位到字幕文件。

### 设置

- 界面语言：标题栏左侧下拉菜单 + 设置页大分段控件；原生语言名，切换即时生效。
- 千问 API：地区分段、Key 输入、眼睛显隐、保存、测试、删除、获取 Key 链接、DPAPI 说明。
- FFmpeg：状态徽章、路径、重新检测、手动选择。
- 输出位置：路径/默认、选择文件夹、恢复默认。
- 隐私：完整的数据流说明。

## 5. 动效与反馈

- 进度步骤使用 16ms 定时器的旋转 Spinner；不追求复杂动画。
- 分段控件/按钮使用 Qt 原生 hover/pressed 状态。
- 没有弹跳、缩放或过度动画；保持安静。
- 错误与完成使用模态弹窗，避免用户错过关键结果。
- 取消后短暂显示“任务已取消”，2.6 秒后恢复默认提示。

## 6. 文案原则

- 中文：短句、动词开头、避免堆叠术语。例如“开始生成字幕”而不是“执行字幕生成任务”。
- English：sentence case；按钮不超过 3 个单词（Generate subtitles / Open folder）。
- 日本語：です・ます调；避免片假名堆砌。
- 所有模型说明都解释“更快/更便宜/更稳”的取舍，而不是只写参数。
- 错误文案必须包含下一步动作（去设置、换模型、检查配额）。
- 三语文案 key 集合必须一致，测试会检查。

## 7. 可访问性与适配

- 正文对比度：`#1D1D1F` / `#F5F5F7`、`#6E6E73` / `#FFFFFF` 均达到可读水平。
- 控件最小高度 30–36px；主按钮 36px。
- 1024×700 下内容可滚动，主操作仍固定右上角。
- 高 DPI 使用 Qt 自动缩放；SVG 图标按 2x 渲染。
- 目前未实现完整键盘导航与屏幕阅读器标签，属于后续改进项。
- 深色模式未实现；不要在文档中声称已支持。

## 8. 设计边界

- 不复制 macOS 窗口的像素级细节；窗口按钮遵循 Windows 的右侧布局。
- 不使用 Apple 商标、Apple 系统图标、SF Pro 字体文件。
- 不使用渐变大面积背景、玻璃拟态堆叠或高饱和霓虹色。
- 不使用“AI 魔法”式的夸张营销语言。
