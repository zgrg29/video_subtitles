## v0.2 — 下一对话候选

按推荐顺序：

1. **干净机器 EXE 验证 + 真实 API 联调**（推荐）
   - 把 `dist\QwenSubtitle-portable-0.1.0-win64.zip` 解压到一台没有 Python/FFmpeg 的 Windows 机器，双击 `QwenSubtitle\QwenSubtitle.exe` 验证。
   - 由用户在该机器设置中输入自己的 Key，跑通大陆版 3.1 + Qwen-MT。
   - 验证国际版与另外两个 ASR 模型。
   - 用 1 小时以上视频验证上传/轮询/长音频。
   - 根据真实返回修正解析。
   - 不把 Key 写进仓库或日志。

2. **自定义业务空间 / Endpoint**
   - 设置页高级选项：Workspace ID、Base URL 覆盖。
   - 强制 HTTPS；上传 host 白名单仍保留。
   - 兼容 `{WorkspaceId}.cn-beijing.maas.aliyuncs.com`。
   - 文档更新。

3. **深色模式**
   - 主题 token 化；Light / Dark / System。
   - 自绘控件读取主题。
   - 持久化并即时切换。
   - 截图对比。

4. **字幕预览与轻量编辑**
   - 视频播放器 + 字幕列表。
   - 修改文本、合并/拆分、时间微调。
   - 导出前预览 ASS 样式。
   - 不改变默认“一键生成”路径。

## 明确不做

- 云端账号系统、团队协作、遥测。
- 把原视频上传到云端。
- 使用真实 Key 的 CI。
- 复制 Apple 商标、SF Pro 字体或系统图标。
- 为了“功能多”而把主界面做成后台管理系统。

## 决策原则

1. 先保证“选视频 → 出字幕”可靠，再加功能。
2. 任何会消耗 token 的自动行为必须让用户可预期；仅原文永远不翻译。
3. 模型选择以用户为准，不静默降级。
4. 隐私是默认值，不是设置项。
5. 视觉改动必须截图验收，不能只改 QSS 就声称“更好看”。
