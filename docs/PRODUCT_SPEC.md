# 产品规格 · 千问字幕 v0.1

## 1. 愿景

让“视频 → 字幕”只发生在几个清晰的桌面操作里：选视频、选语言和模型、点击生成、拿到字幕。用户不需要理解转码、分片、轮询、文件上传或翻译 API。

界面不是后台管理系统，而是一个安静、精致、可信任的小工具。

## 2. 目标用户

- 需要给中文视频配英文字幕、或给外语视频配中文字幕的内容创作者。
- 需要快速生成 SRT/ASS/VTT 的字幕组、课程制作者、剪辑师。
- 希望使用千问模型、但不想自己写脚本或处理 FFmpeg 的普通用户。
- 关心隐私、不愿意上传原始视频或把 API Key 存进项目文件的人。

## 3. 用户故事

1. 作为用户，我希望在设置里粘贴大陆版 API Key，并只保存在本机。
2. 作为用户，我希望导入一个视频，看到文件名、时长和分辨率，确认选对了。
3. 作为用户，我希望选择识别语言和翻译目标语言。
4. 作为用户，我希望选择千问最新的 ASR 模型，也能切换到旧一点/更便宜的模型。
5. 作为用户，我希望选择翻译模型。
6. 作为用户，我希望选择只输出原文、只输出译文，或一个文件里同时有原文和译文。
7. 作为用户，我希望选择 SRT、ASS 或 VTT。
8. 作为用户，我希望点击运行后看到 ASR 和翻译的进度，而不是一个无反馈的转圈。
9. 作为用户，我希望完成后弹窗告诉我成功，并能一键打开输出文件夹。
10. 作为用户，我希望下次打开软件时，模型、语言、格式和界面语言还是我上次的选择。
11. 作为中国用户，我希望界面有简体中文；也希望能切换成 English 或日本語。
12. 作为隐私敏感用户，我希望原视频不上传，API Key 不明文保存，软件不收集遥测。

## 4. 功能需求

| ID | 需求 | 验收要点 |
| --- | --- | --- |
| FR-01 | 导入视频 | 支持拖入和文件选择；显示文件名、容器、时长、分辨率、大小；无音轨时明确报错 |
| FR-02 | 识别语言 | 自动识别 + 常见语种；写入 ASR 请求参数 |
| FR-03 | 目标语言 | 仅译文/双语时可用；与源语言冲突时阻止运行 |
| FR-04 | 内容模式 | 仅原文 / 仅译文 / 原文+译文（两个独立文件）；三选一；持久化 |
| FR-05 | 仅原文跳过翻译 | `output_mode=original` 时**不创建翻译请求**，不消耗翻译 token |
| FR-06 | 格式 | SRT / ASS / VTT；持久化；文件使用 UTF-8 BOM；不覆盖同名文件 |
| FR-07 | 地区 | 大陆版 / 国际版；不同 Key；持久化 |
| FR-08 | ASR 模型 | 默认最新 `qwen-audio-3.1-asr-flash-filetrans`；可选 3.0、Qwen3；持久化；不暗降级 |
| FR-09 | 翻译模型 | 默认 `qwen-mt-plus`；可选 Flash；Lite 因 `AllocationQuota.FreeTierOnly` 暂不提供；持久化 |
| FR-10 | API Key | 设置页粘贴、保存、测试、删除；DPAPI 加密；不写入设置 JSON/日志/源码 |
| FR-11 | 运行进度 | ASR（含提取/上传/轮询）→ 翻译（仅原文时跳过）→ 写出；进度条 + 步骤状态 |
| FR-12 | 完成反馈 | 模态弹窗；显示字幕条数/路径；有「打开文件夹」按钮；工作台保留结果 |
| FR-13 | 取消 | 运行中可取消；取消后回到空闲状态，不留下半成品字幕 |
| FR-14 | 界面语言 | 简中/英/日；默认简中；切换即时生效；持久化 |
| FR-15 | 设置持久化 | 地区、模型、语言、内容模式、格式、界面语言、FFmpeg 路径、输出目录 |
| FR-16 | 隐私 | 原视频不出本机；无遥测；日志不含密钥/媒体内容/完整路径 |
| FR-17 | 公开仓库 | 无真实 Key、个人路径、姓名、邮箱、真实媒体；有扫描脚本 |
| FR-18 | Apple 风格 | 侧栏、圆角卡片、分段控件、克制的蓝色、系统字体、轻阴影、留白 |
| FR-19 | 错误处理 | 无 Key/无音轨/无网络/额度不足/模型无权限时给出可操作的中文/英/日提示 |
| FR-20 | FFmpeg | 自动探测；支持手动指定；缺 FFmpeg 时引导设置 |
| FR-21 | 零环境分发 | 最终用户拿到便携 ZIP，解压后双击 `QwenSubtitle.exe` 即可运行，无需安装 Python、pip 或 FFmpeg；包内内置运行时、Qt、资源与 FFmpeg，且不依赖系统 `%TEMP%` |
| FR-22 | 输出目录回退 | 视频所在目录或指定输出目录不可写时，自动改存到桌面/文档/用户目录/应用缓存，并明确提示实际保存位置，不丢弃已完成的识别和翻译 |

## 5. 非功能需求

- **平台**：Windows 10/11 64 位；DPAPI 是 Windows 专属能力。
- **分发**：便携目录版 ZIP；解压后双击 `QwenSubtitle\QwenSubtitle.exe`，不要求目标电脑有 Python、pip、PySide6 或 FFmpeg，也不需要管理员权限或可写的系统 `%TEMP%`。构建产物通过 GitHub Releases 分发，不提交进 Git。
- **窗口**：默认 1180×800，最小 1024×700；内容可滚动。
- **性能**：2 小时音频提取应可完成；ASR 云端异步，前端不阻塞。
- **可用性**：主操作始终在首屏右上角可见；不要求用户先滚到底部。
- **安全**：密钥不落到仓库；原视频不离开本机；所有外部响应解析容错。
- **可维护性**：核心层不依赖 Qt；UI 文案统一 i18n；核心逻辑有单元测试。
- **可测试性**：不依赖真实 Key 即可运行全部自动化测试。

## 6. 关键交互

### 6.1 初次使用

```text
打开应用
  → 工作台空状态
  → 点击「开始生成字幕」或「选择视频」
  → 无 Key 时提示去设置
  → 设置：选地区 → 粘贴 Key → 保存
  → 回工作台 → 选视频 → 配置 → 运行
```

### 6.2 运行

```text
点击开始
  → 进度卡出现并滚动到可见位置
  → 步骤 1 语音识别（提取音频/上传/提交/轮询）
  → 步骤 2 翻译（仅原文：显示“已跳过”）
  → 步骤 3 写出字幕
  → 100% + 完成弹窗
  → 打开文件夹 / 打开字幕 / 完成
```

### 6.3 输出命名

- 仅原文：`<video stem>.original.<ext>`
- 仅译文：`<video stem>.<target code>.<ext>`
- 双语：`<video stem>.original.<ext>` + `<video stem>.<target code>.<ext>`（两个独立文件）
- 重名：`<video stem>.<target code> (2).<ext>`

## 7. 范围外（v0.1 不做）

- 字幕编辑器 / 时间轴微调 / 实时预览。
- 批量队列、文件夹批量处理。
- 说话人分离、热词、术语表、上下文增强的 UI。
- 账户登录、云端同步、团队协作。
- macOS/Linux 的密钥存储实现。
- 自动更新、崩溃上报、遥测。
- 视频内嵌字幕压制。
- 把原始视频上传到云端。
- 使用真实 API Key 的 CI 集成测试。
